# ObjectCore-AP

Application profile for the Object Core Metadata Profile (OCMDP) of NFDI4Objects. It is a formal extension of DCAT-AP 3.0.1, built on DCAT-AP+ in LinkML. The core comes only from the DCAT-AP family; everything else is an extension mapped to CIDOC CRM and its extensions. The focus is events and object biography.

The pages show the current build: release 0.1.0, 26 classes, 40 slots, 14 event classes, 31 super-properties, 5 valid and 5 invalid examples.

* [Visuals](visuals/index.html): the whole chain from community to export, drawn from the current data
* [Profile](profile.html): classes and slots
* [Crosswalk](crosswalk.html): super-properties to profile elements and DCAT-AP
* [Findings](findings.html): what the example datasets showed

> The namespace `https://w3id.org/nfdi4objects/objectcore-ap/` is provisional until it is registered at w3id.org. DCAT-AP+ has no official release; the profile pins commit 198ac222.
